| **PhonePe** | Secondary | Via Razorpay |

| **Cards** | International | Stripe fallback |

### 4.2 Razorpay Integration

```typescript
// Razorpay is the standard for Indian SaaS
// Free to integrate, ~2% transaction fee

// Supports:
// - UPI (most popular in India)
// - All Indian debit/credit cards
// - Netbanking (all major banks)
// - Wallets (Paytm, PhonePe, etc.)
// - EMI options for annual plans
// - Auto-debit for subscriptions

// Implementation:
// npm install razorpay
// Works with Next.js API routes
```

### 4.3 Billing Considerations

| Consideration | Recommendation |
|---------------|----------------|

## 10. Risks & Mitigations

### 10.1 India-Specific Risks

| Risk | Probability | Impact | Mitigation |
|------|-------------|--------|------------|
| Price sensitivity | High | Medium | Offer generous free tier, annual discounts |
| Payment failures | Medium | Low | Razorpay handles retries |
| Support expectations | Medium | Medium | WhatsApp support, IST hours |
| Slow enterprise sales | High | Medium | Focus on SMBs first |
| Copy-cats | Medium | Low | Move fast, build brand |

### 10.2 Regulatory Considerations

| Requirement | Status | Action |
|-------------|--------|--------|
| **GST Registration** | Required if revenue > ₹20L | Register early |
| **Privacy Policy** | Required | Create India-compliant policy |
| **Terms of Service** | Required | Indian jurisdiction |
| **Data Localization** | Monitor | Keep data in India-region servers if possible |
